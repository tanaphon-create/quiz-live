# ฟลุ๊กถูก — เกมตอบคำถามเรียลไทม์ในห้องเรียน

- `host.html` จอครู: สร้าง/แก้ชุดคำถาม (กำหนดเวลา + คะแนนรายข้อ), เปิดห้อง (PIN + QR), ห้องล็อกเกอร์, คำถาม, เฉลย, อันดับ, โพเดียม, ดาวน์โหลด CSV
- `play.html` จอนักเรียน: ใส่ PIN → เลขประจำตัว → ตั้งชื่อ → แต่งตัวในล็อกเกอร์ → ตอบ → ดูผล (อันดับขึ้นที่มือถือหลังจอครูประกาศครบ)
- โหมด: แข่งเดี่ยว / แข่งเป็นทีม (แบ่ง 2–4 ทีมอัตโนมัติ คะแนนทีม = ค่าเฉลี่ย) / เอาตัวรอด (หัวใจ 1–5 ดวง ผิดหมดทั้งห้องไม่เสียหัวใจ)
- กด QR ในห้องล็อกเกอร์เพื่อขยายเต็มจอ
- CSV เรียงตามเลขประจำตัว พร้อมคอลัมน์แปลงเป็นคะแนนเก็บ
- คะแนน: ตอบถูกได้ 50–100% ของคะแนนข้อ ตามความเร็ว + โบนัสตอบถูกติดกัน (+100 ต่อข้อ สูงสุด +500)

## ความปลอดภัย
- หน้าครูต้องล็อกอิน Google ด้วยอีเมลใน `TEACHER_EMAILS` (js/config.js) เท่านั้น — กฎฐานข้อมูลก็ตรวจอีเมลเดียวกัน
- ชุดคำถามเก็บที่ `quiz/banks/{uid}` อ่าน/เขียนได้เฉพาะเจ้าของ
- เปลี่ยนอีเมลครู: แก้ทั้ง js/config.js และ database.rules.quiz.json แล้ว publish กฎใหม่

## ทดลองในเครื่องเดียว
เปิดผ่านเว็บเซิร์ฟเวอร์ (เช่น `python3 -m http.server`) แล้วเปิด host.html แท็บหนึ่ง + play.html อีกหลายแท็บ

## เล่นจริงข้ามมือถือ (Firebase)
1. Firebase Console → Realtime Database → สร้างฐานข้อมูล → คัดลอก URL ใส่ `databaseURL` ใน `js/config.js`
2. Authentication → เปิด Anonymous
3. นำกฎใน `database.rules.quiz.json` ไปรวมในกฎ Realtime Database
4. อัปโหลดโฟลเดอร์นี้ขึ้นโฮสต์ (GitHub Pages / Firebase Hosting)
